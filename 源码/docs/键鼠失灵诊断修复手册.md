第一部分　本次故障案例完整记录
1.1　问题现象
鼠标、键盘（USB 有线/无线接收器）全部失灵，无法移动光标、无法输入；系统其它功能正常，设备管理器中可见设备但均处于异常状态。
1.2　诊断过程与关键证据
1.2.1　设备状态快照（修复前）

1.2.2　问题码精确定位
pnputil /enum-devices /problem 关键输出：4 个 USB 控制器全部为问题码 39（CM_PROB_DRIVER_FAILED_LOAD，驱动加载失败），Problem Status 为 0xC0000033（STATUS_OBJECT_NAME_INVALID，对象名无效），Driver Name 均为 usbxhci.inf。
1.2.3　驱动文件检查
检查 C:\Windows\System32\drivers\ 下 usbxhci.sys、usbd.sys、usbport.sys、usbhub3.sys、hidclass.sys、mouclass.sys、kbdclass.sys、wdf01000.sys 等 16 个 USB/HID 关键驱动文件：全部存在且体积正常，排除文件被精简删除的可能。
1.2.4　注册表检查（根因所在）
HKLM\SYSTEM\CurrentControlSet\Services\usbxhci 的 ImagePath 值异常：
项目
值
损坏值（修复前）
\SystemRoot\\SystemRoot\System32\drivers\USBXHCI.SYS（连续两个 \SystemRoot\，路径无效）
正常值（修复后）
\SystemRoot\System32\drivers\usbxhci.sys
1.2.5　事件日志佐证
Microsoft-Windows-Kernel-PnP 事件 ID 219（驱动加载失败）：驱动\Driver\USBXHCI 加载失败，状态 0xC000026C（STATUS_DRIVER_UNABLE_TO_LOAD），涉及 4 个 AMD USB 控制器实例。
1.3　根因结论
USB 3.x 主控驱动服务 usbxhci 的 ImagePath 注册表值被写坏（出现连续两个 \SystemRoot\），驱动加载器按错误路径找不到文件，返回 0xC0000033 → 驱动加载失败（0xC000026C）→ 4 个 AMD USB 控制器全部问题码 39 → 键鼠无法枚举。该损坏格式高度疑似精简/优化工具批量改写注册表时产生。

1.5　验证结果
控制器：4 个 AMD USB 控制器状态由 Error 变为全部 OK。
键鼠：真实键鼠（VID_373B、VID_3554 的键盘 + 鼠标）由 Unknown 变为全部 OK。

3.4　稳健性与安全建议
白名单：只修白名单内核驱动服务（usbxhci、usbehci、usbohci、usbhub3、usbhub、usbccgp、usbd、hidusb、mouclass/mouhid、kbdclass/kbdhid、wdf01000 等微软内置驱动）；第三方 \??\ 路径一律跳过，防止误伤反作弊与硬件工具驱动。
备份回滚：任何注册表修改前必做 reg 导出备份，并提供一键回滚（导入备份 + 重启设备）。
强制复检：修复后必须复检（设备状态 + 事件日志增量），不能只报“已执行”；输出成功/失败/遗留三项报告。
幽灵设备：CM_PROB_PHANTOM（幽灵设备）是历史残留记录，不是故障；不得据此误报，只统计真实存在的设备。
权限与界面：需管理员权限运行（自动检测提权）；界面建议：一键诊断 → 结果列表 → 一键修复 → 复检报告。
边界清晰：对“换口/换线/交叉测试/进 BIOS/送修”等无法自动化的项，只做明确指引并标注为“需用户操作”。
