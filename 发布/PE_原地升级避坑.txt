原地升级安装（保住软件 + 注册码）避坑清单
==========================================

适用：离线注册表被占用 / 补服务后仍无键鼠 / 不想全新装机

【和全新安装的区别】
  全新安装 = 清空系统，软件注册码大概率没
  原地升级 = 在现有系统上修复，选「保留个人文件和应用」

【步骤】
  1. PE 有网：下载【和当前一模一样版本】的 Windows 11 ISO
     （你之前日志是 10.0.26200.x → Win11）
     微软官网 Media Creation Tool / 官方 ISO 页面

  2. PE 里双击 ISO 挂载（或用 PE 自带挂载），记住盘符比如 E:

  3. 运行 E:\setup.exe

  4. 关键选项：
     - 选「保留个人文件和应用」
     - 不要选「自定义」「仅保留个人文件」
     - 不要格式化

  5. 等待升级完成自动重启（可能多次）
     你干看着即可，升级过程不需要键鼠操作到最后确认

  6. 进桌面后试键鼠；系统会重建 USB 驱动栈

【DISM 有 ISO 时也可】
  DISM /Image:D:\ /Cleanup-Image /RestoreHealth /Source:E:\sources\install.wim /LimitAccess
  （若是 install.esd 需先导出 wim，新手直接 setup.exe 更简单）

【仍失败】
  PE 备份 C 盘重要文件到其他盘 → 再考虑全新安装
